# 模型下拉菜单

将模型入口放在提示词输入框底部，位于尺寸信息左侧，与生成按钮同一行。相比顶部工具栏，它更靠近发起生成的操作；相比右侧参数栏，它在参数栏收起时依然可见。

使用原生 SwiftUI Menu 与 Picker，展示当前选择和选中标记。目前仅列出已支持的 Qwen-Image-2.1，显示 Viggle v0.3 / BF16 信息，并提供「模型设置…」入口。生成或环境检查期间禁用选择，避免正在运行时更改模型。

移除右侧固定模型卡片和顶部重复的模型名称。模型选择由 AppStore 管理；当前只有一个受支持的推理模型，继续使用现有设置中的本地模型路径与配置，不变更历史文件格式。

验证：编译 Release 应用，运行现有 Swift 核心检查；在界面中验证菜单展开、选中标记、设置入口，以及参数栏收起后的布局。
