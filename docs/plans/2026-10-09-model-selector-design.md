# 模型下拉菜单

将模型入口放在提示词输入框底部左侧，与生成按钮同一行。尺寸信息统一显示在右侧生成参数中，输入框底部不重复展示。相比顶部工具栏，它更靠近发起生成的操作；相比右侧参数栏，它在参数栏收起时依然可见。

使用原生 SwiftUI Menu 与 Picker，展示当前选择和选中标记。目前仅列出已支持的 Qwen-Image-2.1，显示 Viggle v0.3 / BF16 信息，并提供「模型准备」入口，展开右侧栏并滚动到顶部的模型路径设置。生成或环境检查期间禁用选择，避免正在运行时更改模型。

移除右侧固定模型卡片和顶部重复的模型名称。模型选择由 AppStore 管理；当前只有一个受支持的推理模型，继续使用现有设置中的本地模型路径与配置，不变更历史文件格式。

验证：编译 Release 应用，运行现有 Swift 核心检查；在界面中验证菜单展开、选中标记、设置入口，以及参数栏收起后的布局。

## 设置分区

左下角齿轮弹窗仅编辑源码目录、Python 和结果目录。右侧顶部「模型准备」直接编辑模型目录和 Config 配置，下方「生成参数」仅保留画面尺寸预设、宽高输入和随机种子（含随机开关）。移除推理细节、尺寸说明、测试快捷按钮、当前作品信息和硬件信息卡片。复用路径输入组件，分别选择目录或配置文件。

两处保存均合并到最新 AppSettings，保留另一分区的值；通用设置恢复默认时仅修改自己的三个路径。模型输入草稿由 AppStore 管理，收起右栏或保存通用设置不丢失草稿。模型设置未保存时提示先保存并禁用生成，支持撤销输入。保存后沿用已有环境检查和 JSON 持久化，不变更历史格式。

验证保存模型设置、保存通用设置、恢复通用默认路径和重启后的持久化；确认两类设置互不覆盖。
